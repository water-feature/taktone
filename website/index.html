taktone

Digitakt firmware on original Digitone hardware.

Independent community project. Not affiliated with Elektron.

Patch firmware · Installation · Documentation

Create patched firmware

Convert stock or compatible modified Digitakt 1.53 or 1.54 firmware for the original Digitone. This is the core patcher; scenes and Sophie machines belong to the separate extended package.

All firmware processing stays on your computer. Your firmware is never uploaded. There are no analytics or server-side patching. The patching engine downloads from this site when you start a build.

Before installing, read the recovery guide and back up your instrument data. First installation requires preparing the +Drive and erases existing data. Keep generated firmware private.




Select factory Digitakt and Digitone firmware, plus modified firmware if converting a mod.

What the patcher changes

Button and LED mapping, Digitone codec initialization and audio I/O, and shutdown autosave. The secondary ColdFire stays idle. VOICE opens SAMPLE; SYN2, NOTE/KEYBOARD and T1–T4 are unassigned.

Your input’s firmware version label is preserved. Converted mods retain their own features when compatible.

What the patcher verifies

The browser runs the current Python converter with the same exact stock hashes, version fingerprints, source/recipe checks, mod compatibility checks, ColdFire instruction audit, container checksums, flash bounds and decompression checks. Both output files must pass before either download appears.

Four supplied 1.53-based mods have user-reported hardware success. The 1.54 profile has software validation; separate hardware qualification is still needed. A successful conversion is not a hardware test.

Install the converted firmware

  1. Back up instrument data and read the installation and recovery guide. Have a DIN MIDI interface and original Digitone firmware available for recovery.
  2. Select your firmware files above, create the converted firmware and save both verified downloads and the report.
  3. Use taktone-…-recovery.syx for the Digitone startup recovery receiver over physical DIN MIDI. Use taktone-….syx when updating from a running Digitakt-based installation. Follow the guide for first-install USB support and the correct receiver.
  4. On first switching from stock Digitone, format the +DRIVE to create Digitakt sample storage.
